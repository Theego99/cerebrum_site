# Studio Cerebrum

The live website is https://studiocerebrum.site/. GitHub Pages publishes the repository root from main.

The homepage presents the studio's work and both makers, musucus and otumn., using their original logos. It includes EN/JP copy, work filters and enquiry details. Prices and availability are confirmed by the studio; musucus purchases use the existing BASE shop.

Edit index.html, style.css, logo-palette.css and app.js. Optimized web images are in assets; original JPEGs remain alongside them. The former commerce-preview address redirects to the live homepage.

shopify-extension contains prepared theme components for a future native Shopify checkout. It is not connected to an active Shopify store.
